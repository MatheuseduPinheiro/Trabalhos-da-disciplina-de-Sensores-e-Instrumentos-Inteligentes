# Trabalhos - Sensores e Instrumentos Inteligentes

## Sobre a Disciplina

Disciplina focada no uso de **sensores e instrumentos inteligentes** utilizando:

- **Arduino Science Journal** para coleta de dados
- **Sensores modernos** (acelerômetros, giroscópios, magnetômetros)
- **Análise de dados** com Python/Pandas
- **Aplicações IoT** e sistemas embarcados
